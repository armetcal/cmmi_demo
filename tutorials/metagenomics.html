Metagenomics – Tutorial

GitHub Repo

Overview

This tutorial walks through the CMMI metagenomics pipeline step-by-step. You should have access to Sockeye / Compute Canada and have your FASTQ files in the appropriate project directory before starting.

Step 1 – Quality Control

Run fastp on each pair of FASTQ files to remove low-quality reads, trim adapters, and generate a QC report. 

fastp \
  --in1 sample_R1.fastq.gz \
  --in2 sample_R2.fastq.gz \
  --out1 sample_R1_clean.fastq.gz \
  --out2 sample_R2_clean.fastq.gz \
  --html sample_qc.html \
  --thread 8

Review the HTML report and flag any samples with <10 M clean reads.

Step 2 – Host Read Removal

Align reads against the human reference genome (hg38) using Bowtie2 and retain only unmapped reads. 

bowtie2 \
  -x /ref/hg38/hg38 \
  -1 sample_R1_clean.fastq.gz \
  -2 sample_R2_clean.fastq.gz \
  --un-conc-gz sample_nonhost.fastq.gz \
  -p 16 \
  -S /dev/null

Step 3 – Taxonomic Profiling

Run MetaPhlAn4 on the host-free reads.

metaphlan \
  sample_nonhost.fastq.gz \
  --input_type fastq \
  --bowtie2db /ref/metaphlan4_db \
  --nproc 16 \
  -o sample_metaphlan.txt

Step 4 – Functional Profiling

Run HUMAnN3 to obtain gene family and pathway abundances.

humann \
  --input sample_nonhost.fastq.gz \
  --output sample_humann/ \
  --threads 16 \
  --nucleotide-database /ref/chocophlan \
  --protein-database /ref/uniref90

Join outputs for downstream R analysis:

humann_join_tables \
  --input /path/to/humann_outputs \
  --output all_genefamilies.tsv \
  --file_name genefamilies

Step 5 – Build phyloseq Object

Import the MetaPhlAn and HUMAnN output tables into R and construct a phyloseq object for downstream statistical analysis.

Troubleshooting

  • Ensure Conda environment cmmi-mg is activated before running any step.
  • If MetaPhlAn fails with a database error, re-download with metaphlan --install.
  • HUMAnN nucleotide search can be slow — allow 4–8 h per sample on a 16-core node.
