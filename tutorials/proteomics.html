Overview

This tutorial describes the CMMI DIA proteomics workflow using DIA-NN for spectral library generation and database search, followed by statistical analysis with MSstats in R.

Step 1 – Spectral Library Generation

Generate a project-specific library from DDA runs using DIA-NN's gas-phase fractionation (GPF) mode: 

diann \
  --f "dda_run_1.raw" "dda_run_2.raw" \
  --lib "" \
  --threads 16 \
  --verbose 1 \
  --out "library.tsv" \
  --fasta /ref/uniprot_human_gut.fasta \
  --fasta-search \
  --min-fr-mz 200 --max-fr-mz 1800 \
  --cut K*,R* \
  --gen-spec-lib

Step 2 – DIA Database Search

diann \
  --f "dia_run_1.raw" "dia_run_2.raw" \
  --lib "library.tsv" \
  --threads 16 \
  --verbose 1 \
  --out "report.tsv" \
  --out-lib "report.lib.tsv" \
  --qvalue 0.01

Step 3 – Import into R (MSstats)

library(MSstats)
library(tidyverse)
raw <- read_tsv("report.tsv")
meta <- read_csv("sample_metadata.csv")
input <- DIANNtoMSstats(raw,
                        annotation = meta,
                        global_qvalue_cutoff = 0.01)
processed <- dataProcess(input,
                          normalization = "equalizeMedians",
                          summaryMethod = "TMP",
                          MBimpute = TRUE)

Step 4 – Differential Abundance

contrast <- matrix(c(-1, 1), nrow=1,
                   dimnames=list("IBD_vs_control",
                                 c("control", "IBD")))
result <- groupComparison(contrast, processed)
sig    <- result$ComparisonResult |>
          filter(adj.pvalue < 0.05, abs(log2FC) > 1)

Troubleshooting

  • Low protein IDs — check that the FASTA database matches the sample source.
  • High missing rate (>50%) — lower the Q-value threshold or increase input protein.
  • MSstats convergence warnings — check that each protein has ≥2 peptides.
