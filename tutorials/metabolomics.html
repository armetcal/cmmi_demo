Metabolomics – Tutorial

GitHub Repo

Overview

This tutorial describes the CMMI untargeted LC-MS metabolomics workflow. Raw .mzXML files are processed with XCMS in R to detect, align, and annotate metabolite features.

Step 1 – Convert Raw Files

Convert vendor-format raw files to open format using MSConvert (ProteoWizard): 

msconvert sample.raw \
  --mzXML \
  --filter "peakPicking vendor msLevel=1-2"

Step 2 – Peak Detection (XCMS)

library(xcms)
library(tidyverse)
files <- list.files("mzxml/", pattern="\\.mzXML$", full.names=TRUE)
pd    <- read_csv("sample_metadata.csv")
raw  <- readMSData(files, pdata=new("NAnnotatedDataFrame", pd), mode="onDisk")
cwp  <- CentWaveParam(ppm=10, peakwidth=c(5,30))
xdata <- findChromPeaks(raw, param=cwp)

Step 3 – Alignment & Gap Filling

obp   <- ObiwarpParam(binSize=0.6)
xdata <- adjustRtime(xdata, param=obp)
pdp   <- PeakDensityParam(sampleGroups=pd$group, minFraction=0.5)
xdata <- groupChromPeaks(xdata, param=pdp)
xdata <- fillChromPeaks(xdata)
feat  <- featureValues(xdata, value="into", missing=0)

Step 4 – Normalisation

Apply probabilistic quotient normalisation (PQN) and log-transform:

pqn_norm <- function(mat) {
  ref <- apply(mat, 1, median)
  mat / rep(ref, ncol(mat))
}
feat_norm <- log1p(t(pqn_norm(feat)))

Step 5 – Annotation

Submit feature lists to MetaboAnalyst for pathway enrichment, or use the MetaboAnnotation Bioconductor package for in-house matching.

Troubleshooting

  • Many missing values — lower minFraction or use gap-filling.
  • Poor alignment — try a smaller binSize in ObiwarpParam.
  • Batch effects — include pooled QC samples and apply LOESS correction.
