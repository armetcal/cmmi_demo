Metatranscriptomics – Tutorial

GitHub Repo

Overview

This tutorial covers the CMMI metatranscriptomics processing pipeline. RNA samples require careful handling; ensure the cold-chain protocol was followed and check RIN scores (≥7 recommended) before proceeding.

Step 1 – Quality Control

Run fastp as for metagenomics, but also check strandedness.

fastp \
  --in1 sample_R1.fastq.gz \
  --in2 sample_R2.fastq.gz \
  --out1 sample_R1_clean.fastq.gz \
  --out2 sample_R2_clean.fastq.gz \
  --thread 8

Step 2 – rRNA Depletion Check

Verify that rRNA depletion was effective using SortMeRNA.

sortmerna \
  --ref /ref/sortmerna/rRNA_databases/ \
  --reads sample_R1_clean.fastq.gz \
  --reads sample_R2_clean.fastq.gz \
  --aligned sample_rRNA \
  --other sample_mRNA \
  --threads 8 \
  --fastx --paired_in

Aim for <5% rRNA in the mRNA fraction before proceeding.

Step 3 – Host Removal & Alignment

Align with STAR using a combined host + reference genome index.

STAR \
  --runThreadN 16 \
  --genomeDir /ref/star_hg38_gut/ \
  --readFilesIn sample_mRNA_1.fastq.gz sample_mRNA_2.fastq.gz \
  --readFilesCommand zcat \
  --outSAMtype BAM SortedByCoordinate \
  --outFileNamePrefix sample_

Step 4 – Feature Counting

featureCounts \
  -T 8 \
  -p -s 2 \
  -a /ref/gut_genes.gtf \
  -o sample_counts.txt \
  sample_Aligned.sortedByCoord.out.bam

Step 5 – Differential Expression

Import counts into R for DESeq2 or edgeR analysis.

library(DESeq2)
library(tidyverse)
counts <- read_tsv("merged_counts.tsv")
meta   <- read_csv("sample_metadata.csv")
dds <- DESeqDataSetFromMatrix(countData = counts,
                               colData   = meta,
                               design    = ~ condition)
dds <- DESeq(dds)
res <- results(dds, contrast = c("condition", "IBD", "control"))

Troubleshooting

  • High rRNA carryover (>20%) — re-deplete or consider a new extraction.
  • Low mapping rate (<50%) — check library strandedness parameter (-s).
  • Very few detectable genes — likely a degraded RNA sample; consult the QC report.
