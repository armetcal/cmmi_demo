Bioinformatics Pipelines

MG Metagenomics Pipeline

Shotgun metagenomics: raw FASTQ → quality control (fastp) → host removal (Bowtie2/hg38) → taxonomic profiling (MetaPhlAn4) → functional annotation (HUMAnN3) → phyloseq object.

View Tutorial

MT Metatranscriptomics Pipeline

RNA-seq: raw FASTQ → QC (fastp) → rRNA depletion (SortMeRNA) → host removal → alignment (STAR) → feature counts → DESeq2/edgeR.

View Tutorial

MB Metabolomics Pipeline

Untargeted LC-MS: raw mzXML → peak detection (XCMS) → alignment → annotation (HMDB/KEGG) → normalisation → statistical analysis in R.

View Tutorial

PT Proteomics Pipeline

DIA proteomics: raw spectra → library generation → DIA-NN database search → protein-level quantification → normalisation → differential abundance (MSstats).

View Tutorial

CI Clinical Data Pipeline

Clinical metadata: REDCap export → data harmonisation → QC checks → linkage with omics datasets → R/Python analysis-ready tables.

View Tutorial

Multi-omics Integration

Joint analysis framework combining all four omics layers using DIABLO (mixOmics), MOFA+, or custom R/Python workflows. Produces integrated factor models and co-abundance networks.
