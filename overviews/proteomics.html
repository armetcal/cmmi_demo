Raw Data Workflow

Purpose

To quantify the protein content of biological samples, capturing both host and microbial proteomes. Proteomics provides a direct measure of functional output and can reveal post-translational regulation not visible at the DNA/RNA level.

Data Types

Raw data type(s): Thermo .raw files (DIA mode)

Processed data type(s): protein-level intensity tables, differential abundance results (MSstats), R analysis objects

Data location: Currently stored on Sockeye / Compute Canada
/arc/project/cmmi/proteomics/

Key Considerations

DIA proteomics provides deep, reproducible protein quantification but requires a high-quality spectral library matched to the sample type.
  • Dynamic range: plasma proteomics is dominated by highly abundant proteins (e.g., albumin); depletion may be needed.
  • Meta-proteomics: stool samples contain both host and microbial proteins — separation of these requires a combined database.
  • Missing values: proteins below the detection limit are common; imputation strategies must be considered carefully.

Recommended Tools

  • Database search: DIA-NN, Spectronaut, MaxQuant
  • Statistical analysis: MSstats, limma, DEqMS
  • Pathway analysis: fgsea, clusterProfiler (R)
