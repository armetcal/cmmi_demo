Raw Data Workflow

Purpose

To determine the microbial members of the gut microbiome as well as their functional capacity. Shotgun metagenomics sequences all the DNA in a stool sample, providing simultaneous taxonomic and functional profiling of the entire microbial community.

Data Types

Raw data type(s): FASTQ files (2×150 bp paired-end)

Processed data type(s): tables (taxonomy, gene families, pathway abundances), phyloseq objects (combined tables for analysis in R)

Data location: Currently stored on Sockeye / Compute Canada
/arc/project/cmmi/metagenomics/

Key Considerations

Microbiome data are compositional and not normally distributed — they often require specialised statistical tools. 10.3389/fmicb.2017.02224
  • Compositional: each feature is influenced by every other feature; raw counts are not directly comparable across samples.
  • Distribution: zero-inflated, roughly negative binomial; standard parametric tests are generally inappropriate.
  • Taxonomy: most annotations are bacterial — some archaea and fungi are also detected.
  • Viral annotations are available but via a separate pipeline (see Pipelines page).

Recommended Tools

  • Taxonomic profiling: MetaPhlAn4, Kraken2/Bracken
  • Functional profiling: HUMAnN3 (UniRef90, MetaCyc)
  • Diversity analysis: vegan, phyloseq (R)
  • Differential abundance: DESeq2, ANCOM-BC, MaAsLin2
  • Compositional tools: ALDEx2, ANCOM
