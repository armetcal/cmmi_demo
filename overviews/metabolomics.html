Raw Data Workflow

Purpose

To profile the small-molecule metabolites present in biological samples. Metabolomics captures the downstream products of microbial and host metabolism, providing a functional readout of the microbiome–host interaction.

Data Types

Raw data type(s): mzXML files from LC-MS/MS (untargeted)

Processed data type(s): metabolite intensity tables, pathway enrichment results, R analysis objects

Data location: Currently stored on Sockeye / Compute Canada
/arc/project/cmmi/metabolomics/

Key Considerations

Metabolomics data require careful normalisation and batch correction — technical variation can dominate biological signal if uncorrected.
  • Annotation: only ~30–50% of peaks can be confidently identified using current databases; many remain as unknown features.
  • Matrix effects: different sample types (plasma vs. stool) have distinct extraction and ionisation efficiencies.
  • Batch correction: pooled quality-control (QC) samples must be included in every run.

Recommended Tools

  • Peak detection: XCMS, MZmine3
  • Annotation: HMDB, KEGG, MetaboAnalyst
  • Normalisation: PQN, LOESS, ComBat
  • Statistical analysis: MetaboAnalystR, limma, MaAsLin2
